# 잠결 DJ

유튜브 **모음 영상**(영상 하나에 여러 곡, 설명란에 `00:00 가수 - 제목` 시간표가 있는 영상)을 들으며 잠들 때,
**곡이 바뀔 때마다 제목과 가수를 소리 내어 읽어 주는** 아이폰용 웹앱입니다.

- 곡이 바뀌면: 음악을 잠깐 멈추고 "다음 곡, 아이유, 밤편지"라고 말한 뒤 그 곡의 처음부터 이어 재생
- 눈 감고 **아래 큰 판 아무 데나 톡** → 지금 곡 이름을 다시 말해 주고 **저장한 노래**에 담음
- 못 누르고 잠들어도 **들은 기록**에 밤별로 남음. 아침에 ☆로 저장하거나 "찾기"로 유튜브 검색
- **취침 타이머**: 정한 시간이 지나면 음악을 멈추고 화면 켜두기를 풀어 폰이 잠들 수 있게 함
- **라디오 DJ 소개**: "오늘 유난히 길었다는 분이 신청하셨어요. 아이유의 밤편지입니다."처럼 신청곡을 소개하듯 말함
- **자연스러운 한국어 목소리 · 내 목소리**: Typecast 성우 목소리를 고르거나, 1분 녹음으로 내 목소리를 만들어 DJ로 씀

## 아이폰에서 쓰는 법
1. 배포 주소를 **Safari**로 열고 공유 → **홈 화면에 추가** (앱처럼 전체 화면으로 열림).
   준비(링크·곡 목록·키 입력)와 밤 재생을 **같은 곳**(홈 화면 앱 또는 Safari 한쪽)에서 하세요. 둘은 저장소가 따로입니다.
2. 유튜브 앱에서 모음 영상 **공유 → 링크 복사** → 잠결 DJ에서 **붙여넣기**
3. 곡 목록 준비 (한 번만 하면 영상별로 기억함)
   - **자동**: 설정에 YouTube Data API 키를 넣어 두면 설명란 → 영상 주인이 쓴 댓글 순서로 시간표를 찾음
   - **직접**: 설명란이나 댓글의 시간표를 복사해서 "곡 목록 직접 넣기"에 붙여넣기
4. **재생 시작** 버튼으로 시작 (아이폰은 이 버튼을 눌러야 목소리가 나옴) → 잠자기 화면으로 바뀜
5. 문제가 생기면 **메뉴 열기 → 다시 시작**. 아침에는 메뉴에서 저장한 노래 / 들은 기록 확인

## 목소리
| | 기기 기본 목소리 | Typecast 목소리 | OpenAI 목소리 |
|---|---|---|---|
| 비용 | 무료 | 무료 API 플랜 있음 (1글자 = 1크레딧). 내 목소리는 유료 API 플랜 필요 | OpenAI 사용료 |
| 방식 | 브라우저 음성 합성(speechSynthesis) | 문장을 mp3로 받아 `<audio>`로 재생 | 문장을 mp3로 받아 `<audio>`로 재생 |
| 한국어 | 기기마다 다름 | 한국 서비스의 성우 목소리, 내 목소리 복제 가능 | 외국어 억양이 섞일 수 있음 |
| 아이폰 | **영상이 재생된 뒤 소리가 안 나는 경우가 있음** (실기기에서 첫 마디만 나오고 이후 무음 확인) | 미디어 재생 경로라 더 확실할 것으로 봄 (실기기 확인 필요) | 위와 같음 |

키는 그 기기에만 보관되고 음성이나 멘트를 만들 때만 해당 서비스로 보냅니다. 사용 한도를 낮게 정한 키를 따로 만들어 쓰는 걸 권합니다.
영상을 열면 할 말을 미리 음성으로 만들어 기기에 저장하므로, 영상마다 처음 한 번만 비용이 듭니다.

### 내 목소리 만들기
1. [Typecast API 콘솔](https://typecast.ai/developers/api/)에서 API 키를 받고 유료 API 플랜을 켭니다. Studio 구독과는 별도입니다.
2. 설정 → 목소리 → **Typecast** → 키 저장 → **내 목소리 만들기**
3. 화면의 글을 잠들기 전 말투로 1분쯤 읽거나, 음성 메모 파일을 고릅니다 (5초~150초). 어떤 파일이든 WAV로 바꿔서 보냅니다.
4. 본인 목소리임을 확인하고 **내 목소리 만들기**를 누르면 목소리 목록에서 바로 선택됩니다.

본인 목소리만 등록하세요.

## 라디오 DJ 소개
설정 → **라디오 DJ처럼 소개하기**를 켜면, 곡이 바뀔 때 DJ 멘트로 소개합니다. 멘트는 곡 목록의 곡 아래에서 미리 읽어 볼 수 있습니다.

- OpenAI 키가 있으면 영상마다 멘트를 새로 씁니다 (`dj.js`, 영상별로 저장). 없으면 준비된 멘트 16개를 돌려 씁니다.
- **곡 이름 자리는 앱이 채웁니다.** AI는 `{곡}` 자리가 있는 멘트와 읽는 법만 주고, 앱이 곡 목록과 맞는지 확인해서 끼워 넣습니다. 화면과 저장 목록에는 원래 글자를 그대로 둡니다.
- **곡 이름은 말하듯 읽습니다.** `G-DRAGON_무제(無題) (Untitled, 2014)`는 "지드래곤의 무제입니다", `babymonster_deserve`는 "베이비몬스터의 디저브입니다"처럼 읽고, 세 곡에 한 번은 "가수 ○○의 ○○"로 읽습니다. DJ 소개를 꺼도 적용됩니다.
- **OpenAI 키가 없으면** 괄호·연도는 빼지만 영어 이름은 영어 그대로 읽습니다 ("babymonster의 deserve입니다"). `가수_제목` 형식이 아니면 어느 쪽이 가수인지 몰라서 "아이유, 밤편지"처럼 쉼표로 잇습니다.
- 사연은 분위기를 위해 지어낸 것입니다. 발매 연도, 앨범, 차트처럼 곡에 대한 사실이 들어간 멘트는 버리고 준비된 멘트로 바꿉니다.
- 판을 눌렀을 때는 멘트 없이 곡 이름만 또렷하게 말합니다.

목소리가 안 나오면 **설정 → 음성 진단**을 열어 "진단 내용 복사"로 기록을 확인하세요. 무엇을 언제 말하려 했고,
소리가 시작됐는지, 왜 실패했는지가 남습니다.

## 알아 둘 점
- 웹 페이지라서 **화면이 켜져 있어야** 재생됩니다 (무료 유튜브 앱과 같음). 재생 중에만 화면 꺼짐 방지를 잡고, 멈추거나 끝나거나 오류가 나면 풉니다.
- 올린 사람이 **외부 사이트 재생을 막은 영상**(오류 101/150)은 재생되지 않습니다. 다른 모음 영상을 쓰세요.
- **광고**: 광고를 직접 알아낼 방법은 없고, "본 영상 재생 시각이 흐를 때만 곡 바뀜을 판단"합니다. 영상 앞 광고 동안 안내하지 않는 것은 확인했지만, 중간 광고는 확인하지 못했습니다. 광고 소리 크기나 건너뛰기는 앱에서 다룰 수 없습니다.
- 말한 뒤 음악 자동 재개가 막히면 목소리로 알려 주고, 그다음부터는 "음악 위에 말하기"로 바꿉니다. 판을 한 번 누르면 음악을 다시 틉니다.
- YouTube API 키에 웹사이트 제한을 걸어 두었다면 `https://<아이디>.github.io/*`를 허용 목록에 추가해야 합니다. 키는 기기에 보관하고 곡 목록을 찾을 때만 Google로 보냅니다.

## 배포 — GitHub Pages (무료)
빌드 과정 없는 정적 파일이라 그대로 올리면 됩니다.

1. github.com에서 새 **Public** 저장소 `sleep-dj` 만들기 (README 추가 없이 빈 저장소로)
2. 이 폴더에서
   ```bash
   git init -b main
   git add .
   git commit -m "잠결 DJ"
   git remote add origin https://github.com/<아이디>/sleep-dj.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/sleep-dj/` 접속

## 로컬에서 보기
```bash
python -m http.server 4180 --directory sleep-dj
```
`http://localhost:4180/?v=<영상ID>` 로 열면 그 영상을 바로 불러옵니다.

## 고칠 때 주의
GitHub Pages는 파일을 10분쯤 캐시합니다. 옛 파일과 새 파일이 섞이면 모듈을 못 불러와 앱이 뜨지 않으므로, 파일을 바꾸면
`index.html`과 `import` 줄의 `?v=` 값을 모두 같은 새 값으로 올리세요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 유튜브 플레이어 제어, 곡 바뀜 감지(0.25초 간격), 안내 흐름, 저장/기록, 취침 타이머 |
| `voice.js` | 목소리 채널(한 번에 한 마디, 기기/Typecast/OpenAI 음성), 막힘 풀기·재시도, 음성 진단 기록 |
| `typecast.js` | Typecast API(음성 합성, 목소리 목록·추천, 내 목소리 등록), 녹음과 WAV 변환 |
| `dj.js` | DJ 멘트 요청·검사, 곡 이름 끼워 넣기, 준비된 멘트 (DOM 없는 순수 함수) |
| `tracklist.js` | 시간표 해석, 음성용 문장 다듬기, 링크에서 영상 ID 꺼내기 (DOM 없는 순수 함수) |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 앱 설정과 아이콘 |
